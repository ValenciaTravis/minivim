# Minivim

## 启动

```minivim [options] <filename>```

+ ```-t```: truncation mode
+ ```-R```: read only mode

## 模式

### Insert mode

+ ```Esc```: 切换到normal mode
+ ```Tab```: 自动补全单词
	+ 如果只有一个单词，自动完成补全
	+ 如果再按一次```Tab```，打一个Tab出来
	+ 如果按```=/↓/→```，翻到下一页单词
	+ 如果按```-/↑/←```，翻到上一页单词
+ ```(/[/{/'/"```：自动补全后半。如果下个字符是后半，则不补全
+ ```Enter```：自动对齐上一行的缩进

### Normal mode

+ ```dd```：删除一整行
+ ```0```：跳到行首
+ ```$```：跳到行末
+ ```w```：跳到上一个单词开始
+ ```b```：跳到下一个单词开始

### Command mode

+ ```:w```：保存
+ ```:q```：退出，如果未保存会提示你是否仍然退出
+ ```:q!```：强退
+ ```:wq```：保存并且退出
+ ```:jmp Linenumber```：跳到指定行，如果行号非法，不作任何操作
+ ```:sub```
	+ ```sub "xxx"```：只查找不替换
	+ ```sub "xxx" "yyy"```：查找并且替换
		+ 光标跳转到之后的第一个查找到的单词，如果没有，则跳到最后一个。
		+ 按```↑/↓```移动当前的光标位置
		+ 按```Enter```确定替换

## Feature

+ 支持在命令行全局调用minivim
+ 支持文件用相对路径打开
+ Normal mode没有限制不能移到最后一位（因为知道的时候已经做完了，改起来很麻烦）
+ Insert mode如果光标在行尾，且行尾刚好在屏幕最左端，光标会自动另起一行
+ ```W/b```操作中的单词定义和自动补全不同
	+ ```w/b```：完全由数字、字母、下划线组成的连续子串
	+ ```word-completion```：完全由数字、字母、下划线组成的连续子串，且首位不能是数字
+ 自动补全只统计了文章内出现的单词（如果是cpp，还包含了cpp的一些关键词），但是自己这一次出现是不计入文章内出现的单词的
+ cpp文件下有cpp关键词的高亮
+ sub指令下有查找单词的高亮
+ sub没有做全部替换的功能（因为感觉一般大文件用不到这个功能，小文件一个个替换也不麻烦）
+ 没有保存的新建文件不会被创建（直到第一次保存）
